# WhoIsOnTheBall

Research project on soccer tracking and event data.

## Data

This research uses publicly available data:

| Source | Content | Access |
|---|---|---|
| PFF FC 2022 FIFA World Cup data | Broadcast tracking and event data for all 64 matches | [PFF FC release](https://www.blog.fc.pff.com/blog/pff-fc-release-2022-world-cup-data) |
| EA Sports FIFA 23 player attributes | Player ratings (CC0 on Kaggle) | [Kaggle dataset](https://www.kaggle.com/datasets/sanjeetsinghnaik/fifa-23-players-dataset) |

Raw data is not redistributed here. Please obtain it from the providers above and follow their terms of use.
